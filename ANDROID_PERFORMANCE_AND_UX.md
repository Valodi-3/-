# ANDROID UX, ОПТИМИЗАЦИЯ И ДОСТУПНОСТЬ (ANDROID_PERFORMANCE_AND_UX.md)

> **Статус документа**: Спецификация Фазы 11 по мобильному UX, оптимизации производительности Android и настройкам доступности в игре «The House Remembers» на движке Godot 4.7.2. Все целевые показатели производительности являются нормативными ориентирами для тестирования и подлежат обязательному уточнению при профилировании на реальных мобильных устройствах.

---

## 1. Мобильный Интерфейс и Сенсорная Схема Управления

Схема управления спроектирована под сенсорные экраны Android и обеспечивает полный контроль одной рукой или двумя thumb-пальцами.

```
+-------------------------------------------------------------+
| [Пауза / Дневник]                     [Иконка Фонаря / Статус] |
|                                                             |
|                                                             |
|     ( Virtual )                         (( Context ))       |
|     ( Joystick)                         ((  Button  ))      |
|                                                             |
+-------------------------------------------------------------+
```

### 1.1. Левая Зона: Плавающий Виртуальный Джойстик (`VirtualJoystick`)
* **Активация**: Появляется в любой точке левой половины экрана при касании.
* **Градация сдвига**:
  - *0% - 50% сдвига*: Крадущийся шаг ($70\text{ px/s}$).
  - *50% - 100% сдвига*: Обычная ходьба ($130\text{ px/s}$).
  - *Быстрый двойной тач с удержанием (Double Tap & Drag)*: Спринт ($230\text{ px/s}$).

### 1.2. Правая Зона: Универсальная Контекстная Кнопка (`ContextButton`)
* **Динамическая иконка**: Иконка меняется автоматически на основе сканирования `InteractionRayCast2D` (длина $40\text{ px}$):
  - *У двери*: `[Открыть / Закрыть / Вставить клин]`
  - *У шкафа / занавеса*: `[Спрятаться / Выйти]`
  - *У рубильника*: `[Включить / Выключить]`
  - *У предмета*: `[Взять / Бросить]`
  - *На пустом месте*: `[Переключить стойку: Присед / Ходьба]`

## 2. Читаемость UI на Мобильных Экранах (360–390 dp)

* **Минимальный размер тач-зоны**: Не менее $48 \times 48\text{ dp}$ ($144 \times 144\text{ px}$ на HD-экранах) для исключения промахов.
* **Масштабирование текста**: Шрифты записок и диалогов имеют минимальный размер $16\text{ pt}$ с возможностью увеличения до $20\text{ pt}$.
* **Контрастность UI**: Все элементы интерфейса снабжены темной подложкой с $60\%$ альфа-прозрачностью.

## 3. Градация Профилей Оптимизации Android

| Профиль | Целевой FPS | Оперативная Память (RAM Target) | Метод Оптимизации |
|---|---|---|---|
| **Low (Бюджетные устройства)** | **Стабильные $30\text{ FPS}$** | Target: $< 350\text{ MB}$ *(уточняется профилированием)* | Godot Compatibility, отшелушивание теней, масштабирование рендера 0.75x |
| **Balanced (Средний сегмент)** | **$45–60\text{ FPS}$** | Target: $< 300\text{ MB}$ *(уточняется профилированием)* | Стандартное разрешение, лимит 3 активных источников света |
| **High (Флагманские устройства)**| **Стабильные $60\text{ FPS}$** | Target: $< 250\text{ MB}$ *(уточняется профилированием)* | Полная детализация, мягкие тени |

*Примечание*: Для бюджетного Android базовым критерием приёмки являются стабильные **30 FPS**. Частота **60 FPS** выступает ориентировочной целью для средне-высокого сегмента мобильных устройств.

## 4. Настройки Доступности (Accessibility Settings)

1. **Визуальные альтернативы аудиосигналам (Visual Audio Cues)**:
   - Пульсирующая иконка на краю экрана при приближении Хранителя для слабослышащих игроков.
2. **Режим уменьшенного движения (Reduced Motion)**:
   - Отключение тряски камеры (`Camera Shake`) и эффекта хроматической аберрации при стрессе.
3. **Настройка чувствительности и виртуального джойстика**:
   - Регулировка мертвой зоны джойстика ($10\% - 30\%$) и размера контекстной кнопки ($80\% - 140\%$).
4. **Высококонтрастный режим текста**:
   - Белый текст на черном фоне в журнале и записках.
