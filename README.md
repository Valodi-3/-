# The House Remembers — Game Design Phase 7 Documentation

> **Статус проекта**: Полная спецификация геймдизайна V2.0 для коммерческого психологического 2D Top-Down хоррора на Godot 4 (Android-first, 100% Premium). Все интерфейсы и структуры данных помечаются как предлагаемые до проверки физического кода команды Antigravity.

## Документация Проекта (Phase 7 Index)

1. **[GAME_DESIGN_V2.md](./GAME_DESIGN_V2.md)** — Мастер Game Design Document. Видение проекта, платная бизнес-модель, Android-first управление, 15 объектов окружения, архитектура `MansionMemory.gd` и баланс сложностей.
2. **[ENEMY_AI_DESIGN.md](./ENEMY_AI_DESIGN.md)** — Дизайн ИИ противников. Подробная детализация противников K-01 (Caretaker), K-02 (Servant), K-03 (Observer), их FSM, способностей, слабостей, сингналов и правил взаимодействия с `MansionMemory`.
3. **[LEVEL_PROGRESSION.md](./LEVEL_PROGRESSION.md)** — Детальная прогрессия 5 уровней (`The Entrance`, `The Gallery`, `The Bedrooms`, `The Archives`, `The Heart`) с альтернативными путями, головоломками, взаимодействием с врагами и критериями приёмки.
4. **[ENDINGS_AND_STORY.md](./ENDINGS_AND_STORY.md)** — Нарративный дизайн и 4 сюжетные концовки (A: The Escape, B: The Truth, C: The Replacement, D: The Last Memory), условия их получения и предотвращение случайных сработок.
5. **[IMPLEMENTATION_BACKLOG.md](./IMPLEMENTATION_BACKLOG.md)** — Техническое ТЗ и приоритезированный бэклог задач для команды Antigravity с оценкой в Story Points (SP) и графом зависимостей.
6. **[SYSTEM_DESIGN.md](./SYSTEM_DESIGN.md)** — Архивный системный дизайн предыдущей итерации.
