# The House Remembers — Game Design & Technical Specification (Godot 4 2D Top-Down)

> **Статус документа**: Данная спецификация представляет собой проектный план и руководство по дальнейшей разработке (Roadmap/Specification Design), а не доказательство выполненной реализации в коде или прохождения тестов.

Этот репозиторий содержит документацию и спецификацию для хоррор-игры **«The House Remembers»** на движке Godot 4.x в 2D Top-Down формате.

## Документация

* **[SYSTEM_DESIGN.md](./SYSTEM_DESIGN.md)** — Основной системный дизайн-документ и техническое ТЗ для команды Antigravity.

### Разделы документа:
1. **Концепция Хранителя (Keeper AI) и 2D-механика преследования**: строго 2D-узлы (`CharacterBody2D`, `NavigationAgent2D`, `RayCast2D`), отсутствие телепортаций, конус обзора FOV, акустические радиусы, скоростной кайт.
2. **12–15 Интерактивных объектов окружения**: замена огромного инвентаря на прямое взаимодействие с объектами (двери, клинья, шкафы, половицы, шкатулки, масленки, меловые метки).
3. **Прогрессия механик по 5 уровням**: `The Entrance`, `The Gallery`, `The Bedrooms`, `The Archives`, `The Heart`.
4. **Интеграция с системой MansionMemory в Godot**: предложенный профиль сопряжения с `MansionMemory.gd` (для сверки с кодом Antigravity), затухание памяти (decay), блеф.
5. **Управление Android (2D Touch Layout)**: сохранение текущего сенсорного джойстика без изменений до натурных устройств + 1 контекстная кнопка взаимодействия.
6. **Механизм финала, Чекпоинты, Сохранения и Сюжетные Концовки**: полная совместимость с `save_game.json`, обман предсказаний особняка, Основная (True Escape), Секретная и Опциональная Плохая концовки.
7. **Спецификация Уровней 1–5**: конкретные цели, препятствия, обязательные события, альтернативные решения, критерии приёмки (Acceptance Criteria) и оценка сложности в Story Points (SP).
8. **Градация сложности**: Normal, Hard, Nightmare (сохранение минимальных звуковых предупреждений об опасности).
9. **Финальное техническое ТЗ для Antigravity**: 2D структура сцен Godot 4, стейт-машина ИИ Хранителя и логика 2D контекстной кнопки.
