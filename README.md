# The House Remembers — Game Design & Technical Specification

Этот репозиторий содержит документацию и спецификацию для хоррор-игры **«The House Remembers»** на движке Godot 4.x.

## Документация

* **[SYSTEM_DESIGN.md](./SYSTEM_DESIGN.md)** — Основной системный дизайн-документ и техническое ТЗ для команды Antigravity.

### Разделы документа:
1. **Концепция Хранителя (Keeper AI) и честная механика преследования**: исключение телепортаций, зрение/слух, скоростной баланс.
2. **Активный и резервный набор предметов**: 15 ключевых предметов инвентаря.
3. **Распределение механик по 5 уровням**: поэтапный ввод механик.
4. **Интеграция с системой MansionMemory в Godot**: отслеживание привычек, веса, затухание (decay), правила блефа.
5. **Управление Android (Touch Controls)**: плавающий джойстик + 1 динамическая контекстная кнопка.
6. **Сюжетные предметы и Механизм финального спасения**: вещи пропавшего друга (Марка), досье, ритуальное спасение и эскорт.
7. **Конкретизация Уровней 1–5**: цели, препятствия, обязательные события, альтернативные решения и условия победы.
8. **Градация сложности**: Normal, Hard, Nightmare (без Pay-to-Win).
9. **Финальное техническое ТЗ для Antigravity**: структура сцен Godot 4, API синглтона `MansionMemory.gd`, стейт-машина ИИ Хранителя и логика контекстной кнопки.
