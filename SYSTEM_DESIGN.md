# Системный дизайн: «The House Remembers» (2D Top-Down Версия)

> **Статус документа**: Данная спецификация представляет собой проектный план и руководство по дальнейшей разработке (Roadmap/Specification Design), а не доказательство выполненной реализации в коде или прохождения тестов.

---

## 1. Концепция Хранителя (Keeper AI) и 2D-механика преследования

### 1.1. Физическое присутствие и отказ от телепортации
* **2D-физика**: Хранитель — это узел `CharacterBody2D`, перемещающийся строго по навигационной сетке 2D-уровня с помощью `NavigationAgent2D` (A* pathfinding по `NavigationRegion2D` / `TileMapLayer`).
* **Полный запрет телепортации**: Хранитель не появляется из воздуха за спиной игрока и не проходит сквозь запертые двери. Все перемещения между комнатами происходят в реальном времени через дверные проемы и коридоры.
* **Честная реакция**: При обнаружении игрока воспроизводится звуковой/визуальный сигнал настороженности (`ALERT`), и Хранитель имеет фазу задержки реакции (0.4–0.8 сек в зависимости от уровня освещенности и расстояния), давая игроку возможность совершить маневр или зайти за укрытие.

### 1.2. Зрение и слух Хранителя в 2D Top-Down
* **Зрение (2D Cone FOV)**:
  * Реализовано через `Area2D` с коническим коллижен-сектором и сеткой из `RayCast2D` (от 5 до 9 лучей для точной проверки геометрии).
  * Угол обзора: $70^\circ$, дальность $300\text{px}$ при включенном свете / $150\text{px}$ в темноте.
  * Периферийное зрение: $140^\circ$, дальность $100\text{px}$ (детектирует бег или свет фонаря).
  * Препятствия (стены, закрытые двери, шкафы) полностью блокируют `RayCast2D`.
* **Слух (Акустические 2D-радиусы)**:
  * **Крадущийся шаг (Crouch/Stealth)**: $0\text{px}$ (полная бесшумность, кроме скрипучих половиц).
  * **Обычная ходьба**: $100\text{px}$.
  * **Бег (Sprint)**: $280\text{px}$.
  * **Шумное открытие двери / Бросок предмета**: $450\text{px}$.
  * **Сработка интерактивной ловушки (музыкальная шкатулка / звонок)**: $700\text{px}$.

### 1.3. Скоростной баланс и тактический кайт
* **Скорости движения (в пикселях в секунду)**:
  * Игрок в приседе: $70\text{ px/s}$
  * Игрок ходьба: $130\text{ px/s}$
  * Игрок спринт: $230\text{ px/s}$ (ограничен стаминой на 5 секунд непрерывного бега)
  * Хранитель патрулирование: $100\text{ px/s}$
  * Хранитель поиск/расследование: $140\text{ px/s}$
  * Хранитель погоня (Chase): $200\text{ px/s}$
* **Тактика**: Игрок на спринте ($230\text{ px/s}$) быстрее Хранителя ($200\text{ px/s}$). Побег строится на заведении Хранителя за угол, быстрой смене направления и скрытии в тени или интерактивном укрытии до повторного сканирования конуса зрения.

## 2. 12–15 Интерактивных объектов окружения (Environmental Interactions)

Вместо сложного инвентаря геймплей сфокусирован на прямом взаимодействии с окружением уровня.

1. **Деревянная дверь (Wood Door)** — Переключаемый объект (`Open / Closed / Locked`). Закрытие задерживает Хранителя на 2 секунды (анимация открытия); закрытие на замок требует поиска ключа на уровне.
2. **Дверной клин (Door Wedge Node)** — Устанавливается на закрытую дверь, блокируя ее для Хранителя на 6–8 секунд (Хранитель выбивает дверь с шумом).
3. **Шкаф / Гардероб (Wardrobe Hiding Spot)** — 2D-укрытие. Игрок прячется внутри. Если MansionMemory показывает высокий вес `hide_wardrobe`, Хранитель при поиске проверяет именно шкафы.
4. **Кровать / Занавеса (Under-bed / Curtain Spot)** — Альтернативное 2D-укрытие. Позволяет разделять привычки укрытия.
5. **Скрипучая половица (Squeaky Floorboard Area2D)** — Зона ловушки. При наступании издает громкий звук (радиус $450\text{px}$).
6. **Настенный светильник / Рубильник (Light Switch / Fuse Box)** — Включает/выключает освещение в комнате. Свет улучшает видимость игрока, но увеличивает радиус зрения Хранителя.
7. **Музыкальная шкатулка / Напольные часы (Clock / Music Box)** — Заводной источник шума. При активации привлекает Хранителя к своей позиции на 10 секунд.
8. **Стеклянная бутылка на столе (Throwable Bottle)** — Подбираемый в руках объект окружения. Бросается в любую точку радиуса $350\text{px}$ для отвлечения внимания.
9. **Карманная масленка (Oil Dispenser)** — Интерактивный объект. При использовании на скрипучую дверь или половицу делает её бесшумной.
10. **Отмычка на стенде (Lockpick Stand)** — Одноразовый инструмент окружения для взлома быстрых обходных путей.
11. **Меловая доска / Метка на стене (Chalk Marker)** — Позволяет оставить на стене/полу ложную метку. Используется для активации блефа в MansionMemory.
12. **Зеркало обзора (Corner Mirror)** — Установлено на углах коридоров, позволяет игроку видеть конус зрения Хранителя за углом без выхода из тени.
13. **Напольная плитка-тревога (Pressure Plate)** — Плитка, активирующая шум при наступании.
14. **УФ-лампа на стойке (Stationary UV Lamp)** — Проявляет скрытые надписи и направления движения пропавшего друга на стенах.
15. **Дневник / Записка друга (Friend's Note / Dossier)** — Сюжетный объект чтения, открывающий фрагменты истории и подсказки к обману особняка.

## 4. Интеграция с существующей системой MansionMemory в Godot

> **Важно**: Существующий класс `MansionMemory.gd` не заменяется и не переписывается в рамках данного спецификационного документа. Нижеприведенный API является предложенным профилем интеграции и подлежит обязательной сверке с текущим кодом команды Antigravity.

### 4.1. Фиксируемые привычки (Habits Dictionary)
```gdscript
var habit_weights: Dictionary = {
	"hide_wardrobe": 0.0,        # Частота скрытия в шкафах
	"hide_curtain": 0.0,         # Частота скрытия за занавесками/под кроватью
	"door_close_always": 0.0,    # Привычка закрывать за собой двери
	"path_left_bias": 0.0,       # Предрасположенность к левым коридорам
	"sprint_frequent": 0.0,      # Частый бег вместо стелса
	"light_heavy_user": 0.0      # Частое включение света
}
```

### 4.2. Алгоритм Затухания (Decay System)
При переходе между уровнями или каждые 120 секунд пассивного геймплея выполняется формула затухания:
$$W_{new} = W_{old} \times 0.82$$
Это предотвращает «тупиковые» состояния ИИ и позволяет игроку переучивать особняк.

### 4.3. Механика Блефа и Ложного Предсказания (Bluff System)
* Если вес привычки $W(\text{habit}) > 65.0$, Хранитель строит свой маршрут с приоритетом проверки этого паттерна.
* **Пример блефа**: Игрок намеренно формирует высокий вес `hide_wardrobe` на Уровне 2 и 3. На Уровне 4 игрок оставляет мелом ложный знак у шкафа или заводит музыкальную шкатулку рядом с ним. Хранитель тратит 10 секунд на обыск пустого шкафа, пока игрок проходит через противоположный проход.

## 5. Управление для Android (2D Touch Layout)

> **Примечание по джойстику**: Существующая логика и реализация сенсорного джойстика на мобильных устройствах сохраняются без изменений до проведения натурных тестов на целевых Android-устройствах.

Минималистичный интерфейс, оптимизированный под 2D top-down геймплей:

```
+-------------------------------------------------------+
| [Pause / Journal]                     [Item / Status] |
|                                                       |
|                                                       |
|    ( Virtual )                   (( Context ))       |
|    ( Joystick)                   ((  Button  ))       |
|                                                       |
+-------------------------------------------------------+
```

### 5.1. Левый экран: Виртуальный 2D-Джойстик
* Существующий плавающий/аналоговый джойстик проекта.
* Отклонение $< 50\%$: Крадущийся шаг ($70\text{ px/s}$).
* Отклонение $> 50\%$: Обычная ходьба ($130\text{ px/s}$).
* Быстрый двойной тач со сдвигом: Спринт ($230\text{ px/s}$).

### 5.2. Правый экран: Одна Контекстная Кнопка (`ContextButton`)
* Работает от 2D-луча игрока (`InteractionRayCast2D`, длина $40\text{px}$).
* Динамически меняет иконку и действие:
  * **У двери**: `[Открыть / Закрыть / Вставить клин]`
  * **У шкафа / укрытия**: `[Спрятаться / Выйти]`
  * **У рубильника**: `[Вкл / Выкл свет]`
  * **У интерактивного предмета (шкатулка/бутылка)**: `[Использовать / Бросить]`
  * **На пустом месте**: `[Переключить стойку: Присед / Ходьба]`

## 6. Механизм финала, Чекпоинты, Сохранения и Сюжетные Концовки

### 6.1. Финальный механизм на Уровне 5 («The Heart»)
Вместо магического ритуала развязка базируется на **психологическом обмане предсказаний MansionMemory**:
* В ядре особняка (`The Heart`) находится терминал/конструкция памяти особняка и оцепенелый друг (Марк).
* Особняк сгенерировал финальную систему блокировок на основе **наиболее выраженных привычек игрока** за всю игру (данные из `MansionMemory`).
* **Задача игрока**: Чтобы отключить 3 барьера и освободить друга, игрок должен поступить **строго противоположно** своим сформированным привычкам:
  * Если игрок всегда закрывал двери $\rightarrow$ оставить ключевые двери открытыми.
  * Если всегда прятался в шкафах $\rightarrow$ использовать открытые пространства и занавесы.
  * Если всегда избегал света $\rightarrow$ включить все прожекторы зала.
* Каждое разрушенное предсказание вызывает сбой в ИИ Хранителя (оглушение на 8 секунд) и снимает барьер.

### 6.2. Совместимость с сохранениями и Чекпоинты
* **Сохранение совместимости**: Игра использует существующий формат и файл `user://save_game.json`. Все новые поля данных подгружаются через проверку наличия и миграцию схемы при старте без нарушения читаемости прошлых сохранений.
* **Чекпоинты**: Создаются автоматически при переходе между уровнями и при входе в безопасные комнаты (Safe Rooms).
* **Условия поражения**: При коллизии с Хранителем игрок может перезагрузить последний чекпоинт с сохранением текущего прогресса `MansionMemory`.

### 6.3. Сюжетные Концовки
1. **Основная сюжетная концовка — Истинный Побег (True Escape / Main Ending)**:
   * *Условие*: Игрок обманул 3 предсказания особняка на Уровне 5, освободил Марка и вывел его через Главный Холл.
   * *Финал*: Игрок и Марк покидают особняк. Память особняка перезаписывается, Хранитель деактивируется.
2. **Секретная сюжетная концовка — Разгадка Особняка (Secret Ending)**:
   * *Условие*: Нахождение всех 4 Досье прошлых посетителей + выполнение истинного побега без единого обнаружения Хранителем за всю игру.
   * *Финал*: Игрок не просто сбегает, но и уничтожает источник аномалии особняка, навсегда освобождая прошлые жертвы.
3. **Дополнительная концовка — Застрявший в Памяти (Optional Bad Ending)**:
   * *Опциональный сценарий*: Если игрок пытается пройти Уровень 5 силовым путем, не меняя привычек. Особняк перекрывает пути, зажимая игрока в тупике.

## 7. Спецификация Уровней 1–5: Цели, События, Критерии Приёмки и Оценка Сложности

### 7.1. Level 1: The Entrance
* **Цель**: Найти ключ от крыла Галереи и разблокировать выход из вестибюля.
* **Препятствия**: Запертые двери, 2 зоны скрипучих половиц, базовый патруль Хранителя.
* **Обязательные события**: Нахождение зажигалки друга, вводный показ Хранителя (проход по верхнему балкону).
* **Альтернативные решения**:
  * *Вариант А (Стелс)*: Обойти скрипучие половицы по ковровой дорожке, отпереть боковую дверь отмычкой.
  * *Вариант Б (Отвлечение)*: Бросить бутылку в противоположный угол, выманив Хранителя от стола с ключом.
* **Условие победы**: Открытие двери в `The Gallery`.
* **Критерии приёмки (Acceptance Criteria)**:
  1. Хранитель перемещается строго по `NavigationRegion2D` без телепортации.
  2. Взаимодействие с дверями и бутылками корректно отрабатывает через `ContextButton`.
  3. `MansionMemory` корректно записывает первичные веса движения.
* **Оценка сложности**: **3 SP** (Простой уровень, отладка базовой 2D-физики).

### 7.2. Level 2: The Gallery
* **Цель**: Найти Досье №1 и пробиться к спальному крылу через залы с картинами.
* **Препятствия**: Картины-тревоги (издают шум при свете фонаря), рубильники света, узкие проходы.
* **Обязательные события**: Нахождение очков друга, проявление УФ-надписей на стенах.
* **Альтернативные решения**:
  * *Вариант А*: Отключить рубильник света и пройти галерею в полной темноте по памяти.
  * *Вариант Б*: Заблокировать клином центральную дверь и заставить Хранителя идти в обход через весь зал.
* **Условие победы**: Переход в зону `The Bedrooms`.
* **Критерии приёмки**:
  1. Свет от `PointLight2D` динамически меняет FOV Хранителя.
  2. УФ-источник проявляет скрытый слой `TileMapLayer`.
* **Оценка сложности**: **5 SP** (Средняя сложность, настройка 2D-освещения и тревог).

### 7.3. Level 3: The Bedrooms
* **Цель**: Найти Записную книжку друга и ключ от архива в жилом секторе.
* **Препятствия**: Большое количество комнат и укрытий (шкафы, занавесы), музыкальные шкатулки.
* **Обязательные события**: Событие-перехват: Хранитель закрывает один из главных коридоров.
* **Альтернативные решения**:
  * *Вариант А*: Смазать масленкой двери 3 комнат, создав кольцевой бесшумный маршрут.
  * *Вариант Б*: Оставить мелом ложную метку на шкафу (блеф), заставив Хранителя проверять пустую комнату.
* **Условие победы**: Открытие спуска в `The Archives`.
* **Критерии приёмки**:
  1. ИИ Хранителя проверяет шкафы на основе `habit_weights["hide_wardrobe"]`.
  2. Механика блефа корректно отвлекает ИИ от реальной позиции игрока.
* **Оценка сложности**: **5 SP** (Настройка логики адаптации MansionMemory).

### 7.4. Level 4: The Archives
* **Цель**: Получить Досье прошлых жертв и карту ядра особняка.
* **Препятствия**: Лабиринт из стеллажей, напольные плитки-тревоги, зоны глубокой тени.
* **Обязательные события**: Обнаружение часов друга, активация формулы затухания памяти (Decay).
* **Альтернативные решения**:
  * *Вариант А*: Перенастроить напольные плитки с помощью отмычки, превратив их в ловушку для Хранителя.
  * *Вариант Б*: Использовать резкую смену стиля (с перехода со стелса на бег), сбив накопленные веса MansionMemory.
* **Условие победы**: Доступ к `The Heart`.
* **Критерии приёмки**:
  1. Затухание памяти `process_decay()` корректно снижает веса привычек на $18\%$.
  2. Плитки-тревоги генерируют акустический сигнал для `HearingArea2D`.
* **Оценка сложности**: **8 SP** (Высокая сложность, алгоритмы Decay и лабиринтная навигация).

### 7.5. Level 5: The Heart
* **Цель**: Разрушить 3 предсказания особняка, освободить Марка и совершить эскорт-побег.
* **Препятствия**: Прямое противостояние с адаптированным Хранителем, необходимость ломать собственные привычки.
* **Обязательные события**: 3 фазы разрушения предсказаний, пробуждение друга, финальный эскорт к выходу.
* **Альтернативные решения**:
  * *Вариант А (Истинный путь)*: Точное выполнение противоположных действий для нейтрализации Хранителя.
  * *Вариант Б (Прямой путь)*: Попытка прорыва с использованием оставшихся предметов окружения (клинья/бутылки) $\rightarrow$ приводит к Концовке Б.
* **Условие победы**: Пересечение дверей вестибюля (Концовка А, Б или Секретная).
* **Критерии приёмки**:
  1. Терминал ядра считывает максимальные веса из `MansionMemory` и формирует условий разблокировки.
  2. Фаза эскорта корректно поддерживает скорость движения 2D-спутника.
  3. Отработка логики выдачи соответствующей концовки.
* **Оценка сложности**: **8 SP** (Сложная логика финала и проверка всех систем).

### 9.2. Предлагаемый интерфейс для сверки с `MansionMemory.gd`

```gdscript
# ВНИМАНИЕ: Предложенный интерфейс интеграции для сверки с реальным классом Antigravity
extends Node

signal habit_threshold_reached(habit_id: String, current_weight: float)
signal memory_decay_processed()
signal bluff_triggered(target_position: Vector2)

var habit_weights: Dictionary = {
	"hide_wardrobe": 0.0,
	"hide_curtain": 0.0,
	"door_close_always": 0.0,
	"path_left_bias": 0.0,
	"sprint_frequent": 0.0,
	"light_heavy_user": 0.0
}

var current_difficulty: String = "NORMAL"

func record_habit_action(habit_id: String, weight_delta: float) -> void:
	if habit_weights.has(habit_id):
		var multiplier: float = 1.0
		if current_difficulty == "HARD": multiplier = 1.5
		elif current_difficulty == "NIGHTMARE": multiplier = 2.5

		habit_weights[habit_id] = clamp(habit_weights[habit_id] + (weight_delta * multiplier), 0.0, 100.0)

		if habit_weights[habit_id] >= 65.0:
			emit_signal("habit_threshold_reached", habit_id, habit_weights[habit_id])

func process_decay() -> void:
	var decay_rate: float = 0.82
	if current_difficulty == "NORMAL": decay_rate = 0.75
	elif current_difficulty == "NIGHTMARE": decay_rate = 0.92

	for key in habit_weights.keys():
		habit_weights[key] *= decay_rate
	emit_signal("memory_decay_processed")

func register_bluff_event(target_position: Vector2) -> void:
	emit_signal("bluff_triggered", target_position)

func get_dominant_habit() -> String:
	var max_weight: float = 0.0
	var dominant: String = ""
	for key in habit_weights.keys():
		if habit_weights[key] > max_weight:
			max_weight = habit_weights[key]
			dominant = key
	return dominant
```

### 9.3. Состояния ИИ Хранителя в 2D (`KeeperStateMachine`)

1. **`PatrolState`**:
   * Перемещение по точкам `Marker2D` с помощью `NavigationAgent2D`.
   * При высоком весе `hide_wardrobe` строит свой путь с заходом к ближайшим 2D-шкафам.
2. **`InvestigateState`**:
   * Вызывается при попадании шума в `HearingArea2D`.
   * Хранитель движется к `Vector2` источнику шума со скоростью $140\text{ px/s}$.
3. **`ChaseState`**:
   * Вызывается при пересечении `VisionArea2D` с подтверждением от `RayCast2D`.
   * Движение к игроку со скоростью $200\text{ px/s}$.
   * При потере контакта на 3.5 секунды переходит в `CheckHidingSpotState`.
4. **`CheckHidingSpotState`**:
   * Обыск ближайшего укрытия. При отсутствии игрока или наличии блефа тратит $3.0$ секунды и возвращается в `PatrolState`.

### 9.4. Логика 2D Контекстной Кнопки (`ContextButton.gd`)

* `InteractionRayCast2D` (длина $40\text{px}$) сканирует слой объектов.
* Если перед игроком интерактивный узел `Area2D` / `StaticBody2D` группы `"Interactable"`:
  * Получает имя действия и текстуру иконки.
  * Нажатие на `ContextButton` вызывает метод `interact(player)` у объекта.
* Если объектов нет: кнопка переключает положение приседа (`Crouch`).
