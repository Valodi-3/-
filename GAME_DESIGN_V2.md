# THE HOUSE REMEMBERS — ГЕЙМДИЗАЙН ДОКУМЕНТ V2 (GAME_DESIGN_V2.md)

> **Статус документа**: Полноценная спецификация геймдизайна Phase 7 для коммерческого психологического хоррора на движке Godot 4 (2D Top-Down, Android-first). Совместим с существующей архитектурой проекта Antigravity.

---

## 1. Видение Проекта и Модель Монетизации

### 1.1. Концепция
«The House Remembers» — это премиальный 2D top-down психологический хоррор с акцентом на динамически адаптирующийся искусственный интеллект противников и психологический обман особняка. Игрок исследует мрачный особняк, разыскивая своего пропавшего друга Марка, пока сам особняк и его Хранители изучают каждый шаг, маршрут и привычку игрока.

### 1.2. Коммерческая модель (100% Paid)
* **Единоразовая покупка (Buy-to-Play)**: Игрок получает 100% контента игры сразу после покупки.
* **Полный отказ от монетизационных механик**:
  * Никакой рекламы (Ad-free).
  * Никаких микротранзакций, скинов, лутбоксов или внутриигрового магазина.
  * Никаких платных подсказок, энергии или временных ограничений.
* **Целевые платформы**: Android (первичная целевая платформа, сенсорный интерфейс) с потенциалом портирования на PC/iOS.

## 2. Основной Игровой Цикл (Core Gameplay Loop)

```
[Исследование комнат & Поиск предметов / Записок]
                      │
                      ▼
[Преодоление препятствий / Решение головоломок (2+ пути)]
                      │
                      ▼
[Избегание / Обман Хранителей (K-01 / K-02 / K-03)]
                      │
                      ▼
[Запись действий в MansionMemory (Формирование привычек)]
                      │
                      ▼
[Адаптация Особняка & Блеф / Обман предсказаний в финале]
```

1. **Исследование**: Игрок продвигается по 5 уровням особняка, ища ключи, предметы окружения и сюжетные досье.
2. **Стелс и Навигация**: Избегание контактов с противником с помощью акустических/визуальных укрытий, манипуляций с дверями, светом и звуком.
3. **Адаптация (MansionMemory)**: Каждое действие игрока (выбор укрытий, привычка закрывать двери, частый бег, выбор фланга) увеличивает веса привычек в `MansionMemory`.
4. **Блеф и Взлом систем**: Игрок может сознательно «обучать» особняк ложным привычкам, чтобы затем обмануть его предсказания в критический момент.

## 3. Схема Управления и Интерфейс на Android (2D Touch Layout)

Разработка ведётся под мобильные устройства Android с адаптацией под сенсорный экран.

### 3.1. Сенсорная Схема Управления
* **Левая часть экрана — Плавающий виртуальный джойстик (`VirtualJoystick`)**:
  * *Отклонение 0%–50%*: Крадущийся шаг (Stealth / Crouch) — $70\text{ px/s}$, бесшумное перемещение.
  * *Отклонение 50%–100%*: Обычная ходьба (Walk) — $130\text{ px/s}$, радиус шума $100\text{px}$.
  * *Быстрый двойной сдвиг (Double Tap & Drag)*: Спринт (Sprint) — $230\text{ px/s}$, радиус шума $280\text{px}$ (расходует стамину на 5 секунд).
* **Правая часть экрана — Единая Контекстная Кнопка (`ContextButton`)**:
  * Игрок сканирует окружение через `InteractionRayCast2D` (длина $40\text{px}$).
  * Кнопка динамически изменяет иконку и функционал в зависимости от целевого объекта:
    * *Дверь*: `[Открыть / Закрыть / Установить клин]`
    * *Укрытие (Шкаф / Занавеска / Кровать)*: `[Спрятаться / Выйти]`
    * *Рубильник / Свет*: `[Включить / Выключить]`
    * *Интерактивный предмет (Бутылка / Шкатулка / Масленка)*: `[Подобрать / Использовать / Бросить]`
    * *Пустое пространство*: `[Переключить стойку: Присед / Стойка]`

### 3.2. Минималистичный HUD
```

|                                                       |
|                                                       |
|    ( Виртуальный )                 (( Контекстная ))  |
|    (  Джойстик   )                 ((   Кнопка    ))  |

```

## 4. Совместимость и Техническая Архитектура Antigravity

> **Замечание**: Все интерфейсы и структуры данных являются предлагаемыми проектными спецификациями для команды Antigravity и требуют проверки с фактическим кодом Godot перед внедрением.

### 4.1. Формат Сохранения (`user://save_game.json`)
Формат сохранений обеспечивает 100% обратную совместимость с предыдущими версиями.
```json
{
  "save_version": "2.0",
  "current_level": "Level_01_Entrance",
  "difficulty": "NORMAL",
  "checkpoint_id": "cp_entrance_safe_room_01",
  "player_stats": {
    "health": 1,
    "stamina_max": 5.0,
    "has_lighter": true,
    "inventory": ["key_gallery_main"]
  },
  "mansion_memory": {
    "hide_wardrobe": 42.5,
    "hide_curtain": 12.0,
    "door_close_always": 80.0,
    "path_left_bias": 65.0,
    "sprint_frequent": 15.0,
    "light_heavy_user": 30.0
  },
  "story_flags": {
    "dossier_1_found": true,
    "dossier_2_found": false,
    "dossier_3_found": false,
    "dossier_4_found": false,
    "mark_rescued": false,
    "mansion_truth_unlocked": false
  }
}
```

### 4.2. Автозагружаемые Синглтоны (Autoload Singletons)
* **`MansionMemory`**: Отслеживает веса привычек игрока, рассчитывает затухание (Decay), генерирует сигналы для ИИ противников.
* **`SaveSystem`**: Управляет чтением/записью `user://save_game.json` и контрольными точками.
* **`LevelManager`**: Отвечает за бешовную загрузку 5 уровней, эскорт-механику и смену музыкальных фаз.

## 5. Архитектура Режимов Сложности

Режимы сложности не меняют состав сюжета или противников — все 3 противника (K-01, K-02, K-03) присутствуют в единой сюжетной кампании на всех уровнях сложности.

| Параметр | NORMAL | HARD | NIGHTMARE |
|---|---|---|---|
| **Игровой опыт** | Напряжённое, но доступное прохождение | Высокая цена ошибок, умная адаптация | Честный, но беспощадный вызов |
| **Скорость погони K-01 / K-02 / K-03** | $180\text{ px/s}$ / $190\text{ px/s}$ / $200\text{ px/s}$ | $200\text{ px/s}$ / $205\text{ px/s}$ / $215\text{ px/s}$ | $220\text{ px/s}$ / $225\text{ px/s}$ / $228\text{ px/s}$ *(Игрок спринт $230\text{ px/s}$)* |
| **Угол / Дальность FOV** | 60° / $250\text{px}$ | 70° / $300\text{px}$ | 80° / $380\text{px}$ |
| **Множитель записи привычек ($\Delta W$)** | $1.0\times$ | $1.5\times$ | $2.5\times$ (мгновенный учёт повторяющихся действий) |
| **Скорость затухания памяти (Decay)** | Быстрое ($0.75$) | Умеренное ($0.82$) | Медленное ($0.92$) — особняк почти не забывает |
| **Ресурсы (бутылки, клинья, масленки)** | Избыточные (100%) | Ограниченные (-35%) | Дефицитные (-65%) |
| **Предупреждения об опасности** | Визуальные иконки (глаз/ухо) + звук | Только звуковые индикаторы шагов/дыхания | Минимальные звуковые пульсации |
| **Система Сохранений** | Авточекпоинты в безопасных зонах + при входе на уровень | Чекпоинты только при входе на уровень | Один чекпоинт на уровень, перезагрузка сбрасывает часть ресурсов |

## 6. Защита от Неизбежной Смерти (Softlock / Fair Play Guarantee)

1. **Скоростной резерв (Speed Delta)**: Спринт игрока ($230\text{ px/s}$) **всегда** превышает максимальную скорость любого противника даже на Nightmare ($228\text{ px/s}$), гарантируя физическую возможность оторваться при задействовании стамины.
2. **Правило неполной блокировки пути (K-02 & K-03 Rule)**: Противникам запрещено физически перекрывать 100% доступных маршрутов к ключевой цели. Всегда остается минимум один альтернативный путь (даже если он более длинный или требует расчистки/взлома).
3. **Задержка реакций и фазаAlert**: Противники имеют обязательное окновремени реакций ($0.4–0.8\text{ с}$) при обнаружении игрока, предотвращая мгновенный урон при входе в комнату.
4. **Гарантия Блефа**: Любая сгенерированная блокировка особняка на Уровне 5 разрушается при совершении противоположного действия.
