# Мастер Game Design Document: «The House Remembers» (Version 2.0 / Phase 7)

> **Статус документа**: Центральный проектный документ и спецификация коммерческого психологического хоррора на Godot 4 (2D Top-Down, Android-first). Составлен для команды Antigravity. Все интерфейсы помечаются как предложенные до проверки реального кода.

---

## 1. Видение Проекта и Монетизация

### 1.1. Основная концепция
**«The House Remembers»** — это коммерческий психологический 2D top-down хоррор с акцентом на стелс, исследование и адаптивный ИИ противников. Главный герой отправляется в проклятый особняк на поиски своего пропавшего друга Марка. Особняк обладает памятью (`MansionMemory`), адаптируется к привычкам игрока и использует их против него через трех уникальных противников.

### 1.2. Монетизационная модель
* **100% Premium (Платный продукт)**: Разовая покупка игры в магазинах приложений (Google Play Store).
* **Полный отказ от микротранзакций**: В игре отсутствуют любые формы рекламы, платные косметические предметы, внутриигровые покупки и платные подсказки / Pay-to-Win механики.

## 2. Игровые Платформы и Управление (Android-First 2D Layout)

Игра разработана с первичным фокусом на мобильные устройства под управлением Android с возможностью порторания на ПК.

```
+-------------------------------------------------------+
| [Pause / Journal]                     [Item / Status] |
|                                                       |
|                                                       |
|    ( Virtual )                   (( Context ))       |
|    ( Joystick)                   ((  Button  ))       |
|                                                       |
+-------------------------------------------------------+
```

* **Левая рука**: Плавающий аналоговый джойстик (`TouchScreenButton` / `Control`), контролирующий плавно скорость перемещения ($70\text{ px/s}$ приседание, $130\text{ px/s}$ ходьба, $230\text{ px/s}$ двойной тач-спринт).
* **Правая рука**: Единая контекстная кнопка взаимодействия (`ContextButton`), динамически меняющая иконку от `InteractionRayCast2D` (открытие дверей, скрытие в шкафу, использование масленки, переключение приседа).
* **Верхняя панель**: Минималистичный HUD — доступ к Журналу / Паузе и статус текущего взятого предмета окружения.

## 3. Набор 15 Интерактивных Объектов Окружения

Игра отказывается от сложного инвентаря в пользу прямого взаимодействия с объектами уровня:

1. **Деревянная дверь** — переключение открыто/закрыто/заперто.
2. **Дверной клин** — временная блокировка двери на 6–8 секунд.
3. **Шкаф / Гардероб** — 2D-укрытие от K-01 и K-02.
4. **Кровать / Занавеса** — альтернативное укрытие для разделения привычек.
5. **Скрипучая половица** — шумовая ловушка окружения ($450\text{px}$).
6. **Настенный рубильник** — включение/выключение освещения комнаты.
7. **Музыкальная шкатулка** — запуск звукового сигнала для выманивания врагов.
8. **Стеклянная бутылка** — подбираемый метательный предмет отвлечения.
9. **Карманная масленка** — смазка дверных петель и половиц.
10. **Отмычка на стенде** — инструмент одноразового взлома коротких путей.
11. **Меловая доска / Метка** — инструмент создания ложных следов для блефа.
12. **Зеркало обзора** — просмотр конусов зрения за углами коридоров.
13. **Напольная плитка-тревога** — нажимная шумовая пластина.
14. **УФ-лампа на стойке** — инструмент отпугивания K-02 и поиска надписей.
15. **Дневник / Записка / Досье** — сюжетные читаемые объекты.

## 4. Архитектура MansionMemory и Сохранения

### 4.1. Автозагружаемый узел `MansionMemory.gd`
Фиксирует привычки игрока через веса от $0.0$ до $100.0$:
* `hide_wardrobe` / `hide_curtain`: выбор укрытия.
* `door_close_always`: закрытие дверей за собой.
* `path_left_bias`: выбор фланга при поворотах.
* `sprint_frequent`: частый бег вместо стелса.
* `light_heavy_user`: работа со светом.

### 4.2. Алгоритм Затухания (Decay)
$$W_{new} = W_{old} \times 0.82$$
Выполняется раз в 120 секунд или при смене уровня, предотвращая тупиковые конфигурации ИИ.

### 4.3. Совместимость сохранений (`save_game.json`)
Игра сохраняет полный формат и структуру `user://save_game.json`, подгружая новые поля через безопасные проверки `has()` без поломки старых сохранений.

## 5. Матрица Режимов Сложности

| Параметр | Normal | Hard | Nightmare |
|---|---|---|---|
| **Скорость K-01 / K-02 / K-03** | $170 / 180 / 190\text{ px/s}$ | $190 / 200 / 210\text{ px/s}$ | $210 / 215 / 220\text{ px/s}$ |
| **Коэффициент $\Delta W$** | $+10.0$ | $+18.0$ | $+30.0$ |
| **Индикаторы тревоги** | Визуальные + Звуковые | Звуковые + Помехи | Минимальный тихий шепот |
| **Сохранения** | На каждом чекпоинте | Ограниченные (Safe Rooms) | Строго 1 чекпоинт на уровень |
